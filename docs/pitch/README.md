# Editable pitch

66 seconds, 1080p, English. Actual deployed UI captures with narration. No real-money transactions.

```bash
npm run check
npm run dev
npm run render -- --output ../../public/secondlook-pitch-v2.mp4 --quality high --fps 30
```

The original pre-sprint video remains in the sibling `secondlook-demo-video` workspace. This directory contains the editable v2 composition and only the assets it uses. Audio uses the existing macOS Samantha narrator. The video uses edited still captures, not continuous screen-recorded footage.
