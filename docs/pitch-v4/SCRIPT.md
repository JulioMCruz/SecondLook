# Extended pitch narration

A salesperson says every competitor in Miami already uses AI to answer WhatsApp messages. Should a small business buy the same tool? A confident pitch can create urgency. It does not establish proof. SecondLook helps an owner investigate that claim before committing time and money.

Here is the working product. Start with a claim in English or Spanish. Add the company, location, or timeframe when you know them. The first assessment is free, and judges can enter through Try the demo without waiting for an email code.

Linkup searches the live web and saves the retrieved sources. Nebius then identifies what the evidence does and does not establish. In this example, finding tools that automate WhatsApp is not evidence that every Miami competitor uses one. That distinction changes the next question.

Instead of repeating a broad search, SecondLook proposes a targeted follow-up around the missing proof. The owner can inspect the first sources before deciding whether to unlock deeper research. The value is a narrower, more useful investigation, with a record that stays attached to the original claim.

RevenueCat handles the test checkout. First, a failed purchase: the free assessment stays intact and paid research remains locked. Then, a valid test purchase unlocks the next step. These are clearly labeled sandbox transactions. No real money changes hands.

The backend verifies the entitlement before running paid research, opening the PDF, or sending an attachment. Access is checked on the server, not inferred from a button in the browser. Missing or expired access blocks paid operations while preserving the first look.

With access verified, Linkup performs the focused second search. Nebius builds structured findings: supported, contradicted, or insufficient evidence. Each finding connects to an exact passage from the retrieved material. Open the source and inspect the words behind the conclusion.

A separate review checks whether the passages justify the inference and whether the proposed seller questions are useful. Invalid citations cannot support a finding. If the search adds no proof, the report keeps the uncertainty visible. In this case, insufficient evidence is the honest result.

That result still helps the owner act. The report explains the gap and prepares concrete questions for the seller. The research record also exposes the model, latency, token usage, and estimated cost. Four English and Spanish regression cases passed with valid citations; this is a small test set, not a claim of universal accuracy.

Finally, preview the generated evidence PDF. Keep the claim, findings, source references, and next questions together in a document you can download and discuss. Signed-in email users can also request the attachment. The demo offers the PDF directly, so judges can inspect the deliverable immediately.

SecondLook brings live research, verified paid access, and evidence review into one decision workflow. A free first look earns the next step. A reusable brief carries the value beyond the screen. Try the public app. Before you buy, check the proof.
