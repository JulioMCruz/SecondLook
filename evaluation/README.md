# Evidence evaluations

Run `npm run evaluate` with local Linkup and Nebius credentials. Run `REPLAY=1 npm run evaluate` to reuse the saved search results and re-evaluate the AI.

Four deliberately small English/Spanish cases check clear corporate ownership versus an undefined universal adoption claim. Latest run: 4/4 expected classifications and all citations resolve to retrieved passages. This is a regression set, not a broad accuracy benchmark. The script exits nonzero on failure.

Source excerpts are retrieved third-party material, not verified facts. No real user inputs or credentials are included. Initial exploratory runs remain local; only the final reproducible cases are versioned.
